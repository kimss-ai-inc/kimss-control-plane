# Security Policy

This repository is the public hub for the Kimss Secure Enterprise Agent Control Plane — OpenAPI spec, MCP RBAC examples, and conformance tests for integrators and security engineers.

## Reporting a vulnerability

Email **security@kimss.ai** with subject `SECURITY`. Include the affected repo or endpoint, a description, and steps to reproduce. Do not open a public GitHub issue for security reports.

You can also use GitHub's private vulnerability reporting on this repository (Security → Advisories).

We aim to acknowledge reports within 2 business days and to share a remediation plan or status update within 7 days of confirmation.

Product security and compliance documentation: [https://kimss.ai/trust](https://kimss.ai/trust).
